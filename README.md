# 1️⃣ End-to-End A/B Testing & Causal Impact Analysis Platform

## 📋 Overview

A production-ready platform for analyzing the causal impact of product feature changes on user engagement. This project demonstrates mastery of experimental design, statistical inference, and causal analysis techniques used at top tech companies.

## 🏗️ Architecture

```
project-1-ab-testing/
├── README.md
├── requirements.txt
├── main.py                          # Entry point — runs full pipeline
├── data/
│   └── generate_data.py             # Synthetic experiment data generator
├── src/
│   ├── __init__.py
│   ├── experiment_design.py         # Power analysis & sample size calculation
│   ├── statistical_tests.py         # T-tests, Chi-square, confidence intervals
│   ├── multiple_testing.py          # Bonferroni, Holm, BH corrections
│   ├── simpsons_paradox.py          # Simpson's paradox detection & handling
│   ├── causal_inference.py          # PSM, Difference-in-Differences
│   ├── visualization.py            # All plotting functions
│   └── utils.py                     # Utility functions
├── dashboard/
│   └── app.py                       # Plotly Dash interactive dashboard
└── reports/
    └── technical_report.md          # 5-8 page technical report
```

## 🚀 Quick Start

```bash
pip install -r requirements.txt
python main.py           # Run full analysis pipeline
python dashboard/app.py  # Launch interactive dashboard (http://localhost:8050)
```

## 🔬 Key Features

- **Experiment Design**: Power analysis, minimum sample size calculation
- **Statistical Testing**: Two-sample t-tests, Chi-square tests, confidence intervals
- **Multiple Testing Correction**: Bonferroni, Holm-Bonferroni, Benjamini-Hochberg
- **Simpson's Paradox**: Detection and subgroup analysis
- **Causal Inference**: Propensity Score Matching, Difference-in-Differences
- **Interactive Dashboard**: Real-time statistical analysis visualization
- **Technical Report**: Complete methodology and business recommendations

## 📂 Data Source

The dataset used in this project is **synthetic but realistic**, generated by `data/generate_data.py`. It simulates a real-world e-commerce experiment with:
- **Sample Size**: 100,000+ unique users.
- **Attributes**: User demographics (10+ Countries, 5 Device Types), behavioral segments, and engagement metrics.
- **Complexity**: Embedded "Simpson's Paradox" and confounding variables to test the robustness of the statistical engine.
